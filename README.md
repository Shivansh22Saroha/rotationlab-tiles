# rotationlab-tiles

Static map tiles for [RotationLab](https://github.com/Shivansh22Saroha/pubg_website), served with GitHub Pages at `https://shivansh22saroha.github.io/rotationlab-tiles/v1`.

Generated by `packages/map-tiles` (`pnpm --filter map-tiles run fetch && pnpm --filter map-tiles run build`) from the PUBG developer assets: <https://github.com/pubg/api-assets> (Erangel, Miramar, Rondo; labelled and clean variants, WebP XYZ tiles, z0–5).
